# trading-bot

Laboratorio de análisis y copy-trading **simulado** de memecoins en Solana.

> **Estado:** Fase 1 (investigación, viabilidad, arquitectura y presupuesto), versión 2. Pendiente de aprobación para empezar la Fase 2.
> Todavía no hay código. El proyecto está limitado a simulación: no maneja claves privadas, no firma transacciones y no envía órdenes reales. El modo con dinero real solo se planteará si la simulación cumple los criterios definidos de antemano (apartado 12 del informe).
